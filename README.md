# studio.neyra.vision

Витрина и вход платформы Neyra Vision Studio (Казахстан): от сценария до экрана. Русский и казахский.

- `index.html` — главная (прототип 13.10.2026), статика без сборки; переключатель RU/KZ (`?lang=kz`).
- `scenariy/` — **блок 1 «Сценарий»**: редактор Fountain с живой страницей, сцены/герои/структура/замысел, ассистент NEYRA, экспорт .fountain/.fdx/PDF. Прототип 13.10.2026, пока только русский интерфейс.
  - `scenariy/server.py` — локальный сервер: раздаёт сайт и проксирует запросы ассистента к модели. Ключ — `ANTHROPIC_API_KEY` или файл `~/.config/neyra-studio/key` (одна строка). Без ключа редактор работает, ассистент пишет «ключ не задан».
  - `scenariy/NEYRA-SCENARIST.md` — роль ассистента (по навыку `scenarist` Киностанции). Правится без перезапуска.
  - Проекты хранятся в браузере (localStorage); резервная копия — «Экспорт → .json».
- `assets/` — кадры и логотипы (взяты из neyra.vision и страниц проектов).
- `RAZBOR/` — разбор neyra.ai дословно, инвентаризация того, что у нас есть по Neyra, концепт платформы и сайта, **карта сервисов для сценариев** (`04-SERVISY-SCENARIEV.md`).
- `.claude/launch.json` — локальный просмотр: `python3 scenariy/server.py --port 8769` → http://127.0.0.1:8769/scenariy/
