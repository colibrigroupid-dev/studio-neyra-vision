```sh
cd server

```

Итог: **28 тестов, OK**. Переменная выключает создание лишних `.pyc`;
сама команда unittest соответствует заданию.

Покрыто:

- Действие и камера из кадра; отдельное объяснение каждого `@ImageN`
  до первого использования; язык перед `{репликой}`, шумы в `<…>`,
  постоянный запрет музыки и 16:9; неизвестный референс отклоняется.
- Статичная камера задаётся точной текстовой инструкцией.
  `fixed focus`, неподвижный субъект и отрицание статичности не стирают
  заданное движение. `camera_fixed` отсутствует в payload.
- Длительность 4–15 целых секунд, три разрешения, максимум шесть
  изображений включая первый кадр, роли и порядок, HTTPS/base64,
  отклонение лишних/невалидных данных без обрезки.
- Fake ID, успех без файла и без доступа к ключу/API,
  распознавание fake ID после выключения режима.
- Формат POST/GET, Bearer, таймауты, статусы, сохранение ошибки и usage;
  `expired → failed`, неизвестный/невалидный ответ → 502.
- Отсутствие ключа → 503; HTTP, таймаут и неверный JSON → 502;
  никаких автоматических повторных POST.
- Себестоимость по RAZBOR/15 без наценки: 5 с 720p = $1.155,
  1080p = $2.845, 480p = $0.515.
- Скачивание video/*, сохранение предыдущего файла при обрыве/ошибке,
  очистка временного файла, отказ от HTTPS → HTTP/file редиректа
  до следующего запроса.

## Граница при подключении

README задаёт `sourceVersions={shot, scene, characters, locations}`,
проектный ULID, `studio_id`, цену до запуска, явный запуск,
защиту от повторного запроса, FileAsset дубля и append-only события.
Обязательный язык диалога маршруты передают явно. Порядок `refs_roles`
обязан совпадать с первым кадром и референсами в payload.
Fake-успех не является видеофайлом и не подлежит списанию/утверждению.

Статусы и срок действия URL дополнительно сверены с официальными
[получением задачи](https://docs.byteplus.com/en/docs/modelark/get-video-generation-task-api)
и [созданием задачи](https://docs.byteplus.com/en/docs/modelark/create-video-generation-task-api);
это чтение документации, не вызов генерации. URL нужно скачивать в файл
проекта, а не хранить как постоянный дубль. Доступность модели/ключа,
фактическое списание и экран Production этой сдачей не проверены.
