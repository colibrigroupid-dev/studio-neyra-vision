## Как подключить Claude

В `studio/app.js` заменить местный `const svgPaths = …` одним импортом:

```js
import { svgPaths, illustrations } from './ikonki.js?v=20261013i';
```

Существующий `icon(name)` может использовать эти `d` без изменения формата. Обёртка: `viewBox="0 0 20 20"`, `fill="none"`, `stroke="currentColor"`, `stroke-width="1.5"`, `stroke-linecap="round"`, `stroke-linejoin="round"`; размер 20 px. `illustrations[name]` уже содержит полный `<svg>`, рядом нужен обычный текст пустого состояния.

Прототип: `http://127.0.0.1:8769/dizayn/kabinet-proekta.html` на локальном сервере из README. Для ES-модуля открывать через HTTP, а не `file://`. Он не подключается к серверу команды.
