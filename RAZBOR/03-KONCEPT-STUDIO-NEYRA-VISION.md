# studio.neyra.vision — концепт платформы и сайта (черновик 13.10.2026)

Задача словами Александра: «кинокомпания в Казахстане, которая делает свою платформу, начиная с написания сценария и заканчивая постпродакшном; двигаемся по кашам: сценарий → картинки для ИИматика → страница проекта как лендинг, на которой идёт работа всей команды по ключу и по разделам → работа над каждым кадром отдельно». Сайт — как neyra.ai, но на русском и казахском, по адресу **studio.neyra.vision** (решение 13.10 00:00).

## 1. Что такое платформа — в одной таблице

Платформа = три вещи, которые уже частично есть: **станция** (Claude Code в папке проекта), **Neyra Studio через MCP** (память фильма: сцены, каст, мир, промпты, кадры) и **страница проекта** (где команда видит состояние и работает по разделам). Сайт studio.neyra.vision — витрина и вход.

| Этап («каша») | Что делает команда | Чем делаем | Что выходит | Где видно |
|---|---|---|---|---|
| 1. Сценарий | автор пишет, станция разбирает: читательское заключение, бит-шит, поэпизодник, драфты | Киностанция (навык scenarist), Fountain → PDF | `02-scenariy/draft-NN.fountain`, заключение | раздел «Сценарий» страницы проекта (отрывок + PDF по коду) |
| 2. Герои и мир | портрет + замок внешности, локации 8–20 слов, реквизит, костюм | станция (nano-banana/higgsfield), Neyra: `update_character`, `upsert_world_entity`, Lock Appearance | карты лиц, пластины локаций, библия | «Герои», «Мир» |
| 3. Картинки для ИИматика | кадр на сцену (один выбранный из проб), раскадровка по сценам, озвучка-черновик, склейка в аниматик | Neyra сцены (`import_screenplay` → сцены; концепт → звезда) или снаружи по мастер-промпту; montazh | лист кадров, аниматик mp4 | «Раскадровка», «Аниматик» |
| 4. Страница проекта | собирается из папки проекта; команда входит по ключу роли и работает в своём разделе: продюсер — смета и план, режиссёр — кадры и замечания, сценарист — драфты, оператор — камера | сборщик `build.py` (как у ОРДЫ/Жоламы) + разделы по ключам (как PRO-коды) | `studio.neyra.vision/p/<slug>/` | весь проект |
| 5. Работа над кадром | каждый кадр отдельно: промпт, варианты, выбор, статус красный/зелёный, замечания; 3D-мизансцена при нужде | Neyra Shot Studio / 3D-стенд, `set_scene_shotlist`, `update_scene_prompt`, `lint_prompt`; снаружи — Seedance 2.5 | кадр/клип 16:9 с меткой «принят» | «Кадры» — карточка кадра |
| 6. Видео, звук, пост | клипы по принятым кадрам, голоса, музыка, монтаж, цвет, мастер | Seedance через Neyra Render Lane или welluma-art; zvuk; montazh | мастер + тизер | «Релиз» |

Одобрение на вехах (как у Neyra, ◆): после 1 (сценарий принят), после 3 (аниматик принят), после 5 (кадры приняты), после 6 (финальный монтаж). Пока веха не закрыта, следующий раздел на странице проекта серый.

## 3. Главная — структура и тексты (прототип)

Режим страницы — *убедить*: продюсер/режиссёр/сценарист в Казахстане за 5 секунд понимает «что это» и присылает сценарий. Бриф: кто смотрит — кинокоманды, продюсеры, авторы в КЗ; понять — «весь фильм видно до съёмок, за дни, на нашем языке, права у автора»; действие — «Прислать сценарий».

1. **Первый экран.** Надзаголовок `NEYRA VISION · ПРЕПРОДАКШН ДЛЯ КИНО И СЕРИАЛОВ · ҚАЗАҚСТАН`. H1 «От сценария. / До экрана за дни.» (KZ: «Сценарийден. / Экранға бірнеше күнде.»). Лид: «Увидьте весь фильм до съёмок: актёры, мир, каждый кадр в раскадровке, аниматик и тизер.» Строка: «Короткий метр · Полный метр · Сериал · Под NDA, права остаются у автора». Кнопки «Прислать сценарий» / «Как это устроено». Доверие: «Первое чтение — бесплатно. Продюсер отвечает в течение суток.» Монитор: кадр 16:9 с подписями `СЦЕНА 01 · НАТ. СТЕПЬ · РАССВЕТ`, `REC`, `АНИМАТИК · V1 · 24 К/С`, `TC`.
2. **Путь проекта** (подпись сайта): горизонтальная лента 6 этапов с результатом и вехами ◆ — вместо часов H+00…H+72 у нас этапы 01–06 (нумерация честная, это последовательность).
3. **Что вы получаете** — страница проекта: разбор сценария и оценка · герои и мир · раскадровка и шот-лист · аниматик · промпт на каждый кадр · тизер · смета и план · ключи для команды.
4. **Почему это важно** — обычный путь (7 передач, месяцы) против одной памяти проекта.
5. **Съёмочная группа ИИ** — 28 ролей по отделам, по-русски/по-казахски, без названий моделей; человек-продюсер подписывает каждую передачу.
6. **Пакеты** — Пилот (до 3 минут сценария) · Короткий метр (до 10 мин) · Полный метр (до 30 мин) · Сериал / эпос (до 90 мин). Сроки и цены — **не проставлены**, стоит «смета после чтения сценария». Решение Александра: копировать ли сетку Neyra ($300 / $1 000 / $10 000 / $30 000) или своя в тенге.
7. **Как это работает** — 5 шагов: заявка → подтверждение объёма за сутки → аванс → работа по вехам → релиз и страница проекта.
8. **Вопросы** — 7 вопросов, те же, что у Neyra, с нашими ответами (сроки/цены — «по смете»).
9. **Финал** — «Пришлите сценарий. / Получите фильм.» + Telegram + почта. Подвал: Neyra Vision · Digital Taurus Asia · Алматы; ссылки на neyra.vision, /team/, /kino/.

## 4. Страница проекта по ключу — формат (следующий шаг)

Один шаблон для всех проектов, собирается из папки Киностанции (`PROEKTY/<slug>/`) скриптом `build.py` в `/p/<slug>/index.html`:

- **Замок**: общий код проекта (как TAURUSDGTL/ORDA2026) открывает страницу; **ключ роли** (PRO-код продюсера, код режиссёра, код сценариста) открывает свой раздел с правом отмечать статусы (пока — через правку файлов в папке и пересборку; живые статусы потом через небольшой бэкенд или Artifact DB).
- **Разделы** = этапы из §1: Замысел (логлайн, синопсис, тритмент) · Сценарий (отрывок + PDF) · Герои (портрет, замок внешности, голос) · Мир (локации с пластинами) · Раскадровка (сетка кадров 16:9 по сценам, спецификации моно: `ОБЩИЙ · ДРОН · 24 ММ · 6 С`) · Аниматик (плеер) · Кадры (карточки по одному, статус) · Релиз (тизер, мастер) · Смета и план (по PRO-коду) · Журнал (из ZHURNAL.md).
- **Карточка кадра**: `сцена.кадр`, крупность, движение, объектив, длительность, действие, реплика, промпт (свёрнут), варианты (миниатюры), выбранный ⭐, статус 🔴/🟢, замечание режиссёра, кто и когда принял. Данные — из `03-vizual/kadry/<scena>/<kadr>.md` (фронтматтер) или из Neyra (`get_scenes` → shotlist).
- Источник правды — **папка проекта** (решения живут в файлах, не в чате — правило Киностанции); Neyra — рабочая память для генерации; страница — витрина состояния.

## 5. Хостинг и выкладка

- neyra.vision — GitHub Pages из репо `colibrigroupid-dev/neyra-vision`, DNS на Рег.ру. У одного репо GitHub Pages — один пользовательский домен, значит **studio.neyra.vision = отдельный репозиторий** (например `colibrigroupid-dev/studio-neyra-vision`, корень — эта папка) с файлом `CNAME` = `studio.neyra.vision` и DNS-записью на Рег.ру: `studio  CNAME  colibrigroupid-dev.github.io`. Запись в DNS и создание репо — Александр (как с neyra.vision); пуш из локального клона — как обычно.
- До DNS можно показывать прототип локально (`python3 -m http.server`) или временно положить в `neyra-vision/studio/` — но тогда адрес будет neyra.vision/studio/, не поддомен.
- Код доступа к закрытым страницам проектов — по действующему реестру (TAURUSDGTL, PRO-коды).
