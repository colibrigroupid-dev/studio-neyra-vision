# Голосовые команды в окне проекта: грамматика RU/KK и что они делают (№45)

Основа — `RAZBOR/06` §8: микрофон в каждом разделе, распознавание речи браузера (Web Speech API, `ru-RU` / `kk-KZ`), диктовка в поле или команда. Правило: голос никогда не выполняет платное действие без подтверждения на экране; «принять/вернуть» — только с правом, с показом результата. Всё, что не распозналось как команда, уходит помощнику как вопрос (одно окно, память проекта — №46).

## 1. Как читается фраза

`[глагол] [объект] [номер] [, хвост]` — глагол в начале, номер словами или цифрами («двенадцать три», «12.3», «12-3»), хвост после запятой или паузы — это комментарий/замечание. Распознаватель даёт текст; разбор — простые правила (без нейросети), чтобы работало офлайн и мгновенно:

- числа: «двенадцать три» → `12.3`; «сцена четыре» → `4`; казахские числительные: «он екі үш» → `12.3`.
- объект по умолчанию — раздел, где стоит человек (в «Кадрах» «принять двенадцать три» = кадр 12.3; в «Карте» — клетка).
- не разобрали → не угадываем: показываем «Не понял команду, отправить помощнику?».

## 2. Словарь команд (глагол RU · KK → действие · вызов)

| Команда (RU) | KK | Действие | Что делает платформа |
|---|---|---|---|
| **принять 12.3**, «принят», «зелёный 12.3» | қабылдау 12.3 | кадр/клетка приняты | `POST /approvals {verdict: approved}` или `PATCH /shots/<id> {status: approved}`; нужен `approverRole` |
| **вернуть 12.3, свет не совпадает** | қайтару 12.3, … | вернуть с замечанием | `POST /approvals {verdict: returned, comment: хвост}`; хвост → правило в `KANON.md` «Правила из замечаний» (после «да» на правило) |
| **жёлтый 12.3, …** | сары 12.3 | на доработку без вердикта | `PATCH /shots/<id> {status: review, zamechanie}` |
| **открой сцену 4** / «покажи кадр 12.3» | 4-сахнаны аш / 12.3 кадрын көрсет | навигация | прокрутка/переход в окне, без сервера |
| **ещё четыре 12.3** / «сделай 4 варианта» | тағы төрт 12.3 | новые варианты кадра | собрать задание (`generator.Job`, dry) → **экран подтверждения с ценой** → запуск только по кнопке «Да» |
| **видео 12.3** | 12.3 бейне | ролик из принятого кадра | то же, цена Seedance; запрещено, если кадр не принят (правило «видео после одобрения картинок») |
| **замечание 12.3, …** / «запиши, …» | ескерту 12.3, … | текст в поле замечания/комментария | `PATCH /shots/<id> {zamechanie}` или `PATCH /cells/<id> {comment}` |
| **кто тормозит** / «что ждёт меня» | кім кешіктіреді / мені не күтеді | сводка карты | `GET /map` → «ждёт меня», «мои задачи» → озвучить/показать |
| **в работу 12.3** / «беру 12.3» | 12.3 жұмысқа | взять клетку | `PATCH /cells/<id> {status: working, assignee: я}` |
| **готово 12.3** | 12.3 дайын | сдать на проверку | `PATCH /cells/<id> {status: done}` → сервер ставит `awaiting` апруверу |
| **диктуй** / «пиши» … «стоп» | жаз … тоқта | диктовка в активное поле | текст в поле (сценарий, реплика, комментарий); в сценарии — распознанные «ИНТ./НАТ.» в заголовок |
| **версия** / «зафиксируй сценарий, перед читкой» | нұсқа | версия сценария | `POST /versions {label: хвост}` |
| **помощник, …** / просто вопрос | көмекші, … | вопрос помощнику этапа | окно помощника с контекстом раздела |

Синонимы держим в словаре `studio/golos/slova.json` (RU/KK → команда); числа и форматы номеров — там же. Новый глагол добавляется строкой, без кода.

## 3. Подтверждения и права

- Платное (варианты, видео, портреты): всегда экран «N кадров × M вариантов ≈ X $ / кредитов — Да / Нет». Голосом «да» не принимается — только касание/клик (чтобы случайная фраза не списала деньги).
- Вердикты: сервер сам проверяет `approverRole`; без права — «У вас нет права принимать этот этап», без попытки.
- Каждая голосовая команда пишется в ленту `activity` как обычная операция с пометкой `via: voice`, чтобы было видно, кто и чем командовал.
- Распознанный текст показывается до выполнения на 2 с с кнопкой «отмена» для необратимых действий (вернуть/принять).

## 4. Две ступени голоса

1. **Браузер** (эта грамматика): Web Speech API; казахский в Chrome распознаётся хуже русского — команды короткие, числа цифрами на экране для проверки.
2. **Сервер**: длинные записи (созвоны, читки) → `mlx-whisper` (Mac) / `faster-whisper` (GPU, №25) → текст в журнал/сценарий; через Telegram-бота (№38) голосовое → расшифровка → в проект.
