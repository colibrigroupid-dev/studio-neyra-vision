## Рамка одной строкой
**Ровно четыре страницы: Neyra Writer → Neyra Art → Neyra Director → Neyra Production.** Каждый следующий отдел берёт утверждённое из предыдущего. На странице — только инструменты её отдела. Постпродакшн, монтаж, звук — вне первой версии. Общий чат, лишние счётчики, отладка — не добавлять. Один автор на проект (совместная работа — отдельный объём).

## Сквозные правила (п. 7–8), которые у нас уже совпадают
- Статусы черновик / утверждено / требует проверки — у нас клетки карты (`empty/working/done/awaiting/approved/returned`) и `needsReview` у кадров при смене сцены. Совпадает по смыслу, нужно вывести наружу как три слова Ара.
- Изменение сцены → зависимые помечаются, незатронутые не теряют утверждение — у нас `invalidate_cells` + `needsReview`. Есть.
- Персонаж/локация с постоянным ID, сцены ссылаются на версии — ULID есть; версии образов (варианты) — делать.
- Ключи внешних API на сервере — есть. Платное только по явному «да» — наше правило.
- Один автор: наша команда/роли остаются под капотом, в интерфейсе не выпячивать.

## Дизайн (голосовые Ара)
- **Только чёрное, белое, серое.** Никакой охры и других цветов. «Классика». Сейчас у нас одна охра-акцент — убираем, акцент = белый.
- Механика «как у Viva AI»: четыре связанных блока-ноды, каждый помнит своё.
- Боковая панель NEYRA в Сценарной закрывается и занимает очень мало места.
- Нейронка должна из заголовка сцены и текста сама знать героев и локации — сделано (⌘S + /razbor), это не трогаем.

## Что делаем сейчас (порядок)
1. Навигация окна → четыре отдела: Writer (→ Сценарная), Art (герои + локации одной страницей), Director (раскадровка + кадры), Production (генерация). Проект/команда/токены/страница — в меню проекта. Остальные разделы (карта, разбивка, ИИматик, непрерывность, звук, монтаж, план, журнал, пост) из навигации убираем, права и данные остаются.
2. Монохром: токены цвета без охры (Codex, CSS).
3. Помощник: сворачивается в одну строку, по умолчанию свёрнут вне Writer.
4. Статусы в три слова и кнопки передачи между отделами («Утвердить и передать в Art»), экран Director, Production с очередью — следующими шагами, по доске.
