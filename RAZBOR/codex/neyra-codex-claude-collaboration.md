## Как проходит цикл

1. Пользователь задаёт результат и ограничения здесь, в Codex.
2. Codex готовит изменение и проверяет его. Для задачи, где пишет Claude, последовательность меняется.
3. Координатор передаёт второму агенту задание, актуальные исходники, точную версию или снимок изменений и результаты проверок.
4. Проверяющий возвращает ошибки с файлами, строками и способом воспроизведения. Он отдельно отмечает предположения и предложения.
5. Автор исправляет подтверждённые ошибки, запускает относящиеся к ним проверки и передаёт результат на повторную проверку.
6. Координатор показывает пользователю результат и оставшиеся ограничения. Непрерывный обмен заданиями сам по себе не нужен.

История этого чата автоматически Claude не передаётся. Общий контекст создаётся файлами проекта, заданиями и отчётами. Лимиты аккаунтов Codex и Claude используются отдельно.

## Автоматический вызов проверяющего

Установленный Claude поддерживает неинтерактивный режим `-p`, ограничение инструментов `--tools` и `--safe-mode`. Для автоматической проверки исходников координатор может использовать:

```sh
claude --safe-mode \
  --tools 'Read,Glob,Grep' \
  --allowedTools 'Read' 'Glob' 'Grep' \
  --disallowedTools 'mcp__*' \
  --permission-mode dontAsk \
  --output-format text \
  -p 'Прочитай AGENTS.md и относящиеся к заданию документы, затем независимо проверь текущий прототип neyra.vision. Файлы не изменяй. Сообщи подтверждённые ошибки с приоритетом, файлом, строкой и способом воспроизведения. Отдели предложения от ошибок. Не утверждай, что выполнял тесты или проверял браузер.'
```

Команда запускается из папки проекта. `--safe-mode` отключает пользовательские расширения, hooks и автоматическую загрузку CLAUDE.md; поэтому AGENTS.md явно указан в самом задании. Разрешены чтение и поиск; запуск тестов, Git и браузера здесь выполняет координатор отдельно. `--allowedTools` лишь разрешает вызовы без вопросов, а `--tools` задаёт набор встроенных инструментов.

Это подготовленная команда, а не отчёт об успешном подключении: она ещё не запускалась с запросом к Claude. При первом запуске координатор должен проверить результат и код завершения, а не считать установку инструмента достаточным доказательством связи.
