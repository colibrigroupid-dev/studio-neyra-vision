## 1. Десять правил, по которым платформа собирает каждый промпт

1. **Канон — один файл, вклеивается дословно.** `03-vizual/KANON.md`: стиль (носитель, палитра 60:30:10 в hex, логика света, материалы, объективы), список запретов, замок каждого героя и локации, правила из замечаний. Меняется только там; «edit once → везде» (shotlist-director).
2. **Замок героя = одни и те же слова в каждом промпте** (identity block), отдельно от действия (motion block). Смешение «лицо + движение» в одной фразе = дрейф лица (soul §Identity vs Motion). Табу-детали (2–3 на героя) повторяются в блоке защищённых деталей дословно (Otter, «Матка»).
3. **Без возраста числом в замке.** Фильтры видеомоделей жёстче к числам возраста; возраст несём телосложением и одеждой (Higgsfield ENGINE-RULES). `kanon.py proverka` ловит.
4. **Роли референсов словами**: `REF 1 — @char_tostik canonical identity, match 100%`, `REF 2 — @loc_aul environment and lighting only; the set contains only what this reference shows`. Просто «use the references» смешивает признаки (мастер-промпт §6). Порядок слотов фиксирован на проект: 1 — герой, 2 — костюм, 3 — локация, 4 — композиция (seedance §Per-Image Role Convention).
5. **Одно имя — один элемент**: теги `@char_<slug>`, `@loc_<slug>`, `@prop_<slug>`; изменились пиксели (новое состояние героя, новая пластина) — новое имя `_v2`, не перезапись (seedance §Tag naming). Исходный портрет-замок больше никогда не прогоняется через модель: правки масками поверх (soul §Untouched Base).
6. **Каждый запуск — чистый лист**: модель не помнит прошлых кадров, поэтому в промпте нет «как раньше», «та же», номеров сцен — всё, что должно совпасть, повторяется (seedance §Context isolation). Помнит не модель — помнит платформа (п. 8).
7. **Три источника дрейфа закрываются замками**: локация «дорисовывается» (→ «the set contains only what the reference shows»), рост двоих выравнивается (→ рост в см у обоих), герой в общем плане мельчает (→ «stays the human-sized anchor») (seedance §POSITIVE LOCKS).
8. **Платформа помнит каждый кадр**: карточка `kadry/<кадр>.md` (промпт, статус, кто принял, замечание) + сайдкар происхождения `<кадр>.json` (движок, параметры, референсы с хэшами, цена, версия канона) + `REESTR-KADROV.md` (сводка: вариантов, движок, $, актуален ли канон). Версия канона = хэш файла; изменился канон — реестр показывает устаревшие кадры.
9. **Правка — delta, не переписывание**: «Change only X. Preserve exactly Y» одной правкой за проход; крупный дрейф — новая генерация с каноном, не бесконечный ремонт (мастер-промпт §9, §18, §23).
10. **ИИ учится** = замечание режиссёра к отклонённому кадру превращается в строку раздела «Правила из замечаний» (дата · кадр · кого касается · правило по-английски) и попадает в следующие промпты тех же героев/локаций автоматически (RAZBOR/07 §4). Человек видит и может стереть.

## 2. Три стадии — три сборки из одного канона (`tools/kanon.py sobrat`)

| Стадия | Движок | Форма промпта | Что из канона |
|---|---|---|---|
| Карандаш (черновая раскадровка) | Z-Image Turbo + LoRA | одна строка: триггер, крупность, движение, локация, герои, действие, «no colour, no text» | замки героев/локации, правила; без палитры |
| Картинка (чистовой кадр, портреты, пластины) | Nano Banana 2 | шаблон мастер-промпта §9: REFERENCE ROLES → GOAL → IDENTITY → SCENE → COMPOSITION → LIGHTING → COLOUR → PROTECTED → FORBIDDEN | всё: стиль, палитра, свет, материалы, замки, табу, запреты, правила |
| Видео | Seedance 2.5 | стиль-префикс дословно → Characters → Scene → CUT 1..N → «cuts only at the specified points» (connected-shotlist regime) | всё + continuity/physics/audio-строки |

Действие кадра во всех трёх — английский текст из поля `deystvie_en` карточки (переводит ассистент перед запуском; пустое поле = запуск запрещён). Русское действие остаётся в `deystvie` для команды.

## 3. Где это уже работает

- `tools/kanon.py init|proverka|reestr` — канон из паспортов и `stranica.json`, проверка (пустые поля, возраст числом, нет референса, устаревшие кадры), реестр кадров.
- `tools/raskadrovka.py` — шот-лист из сцен Fountain → промпты карандаша через `kanon.sobrat` → карточки с версией канона → сайдкары сухого прогона через `tools/generator.py` → контактный лист.
- Проба «Ер Төстік», сцены 1–2 (архивная основа А): 17 кадров, ≈114 с, 0 картинок, оценка GPU 0,03 $. Канон черновой: 19 замечаний `proverka` (палитра, свет, табу-детали, референсы — решения худрука/Лены).
