# Разбор интерфейса ChatGPT (десктоп-приложение, 13.10.2026) — и как сделать наш стиль таким же простым

Два экрана от Александра: **профиль** и **главная** (чат/работа). Цвета сняты с пикселей скриншотов (ffmpeg, усреднение 3×3), размеры — в пунктах при масштабе 2×. Скриншоты лежат в `~/Documents/CODE/WEB-MASTER/etalony/chatgpt-app/` (profil.webp, glavnaya.webp). Задача Александра: «наш уникальный стиль для платформы — такой же простой и понятный, как у ChatGPT».

## 1. Что делает его простым (главное, по важности)

1. **Один цвет на всё — графит, 5 ступеней светлоты.** Нет синевы, нет градиентов, нет цветных плашек. Иерархия строится только светлотой: окно → колонка → лист → поле → линия. Единственные цветные пятна — аватар (фиолетовый) и иконки проектов (эмодзи-значки в списке). Акцент действия — **белая кнопка на тёмном** («Обновить»), а не цветная.
2. **Текст двух тонов: белый и серый.** Всё, что надо прочитать, — #ececec–#f0f0f0; всё второстепенное (подписи статов, «@neyravision», «Недавние», подсказки) — #8d8d8d–#a3a3a3. Третьего нет.
3. **Один шрифт (SF Pro / системный), 4 размера.** Заголовок экрана 24–26pt (имя профиля, «Над чем поработаем?»), заголовок раздела 17pt («Витрина», «Недавние»), текст 15–16pt (пункты меню, проекты, подсказки), подпись 13pt (значения-подписи статов, «Сброс в 07:59»). Жирности две: 400 и 600. Никаких капс-меток с разрядкой.
4. **Всё округлое, но одной мерой.** Карточки и панели 16px, кнопки — пилюли 999px, поле ввода 24px, аватар круг. Границы 1px #2a2a2a–#383838, тени почти нет.
5. **Экран почти пустой.** Главная: сверху сегмент «Чат / Работа», в центре вопрос и одно поле, под ним три подсказки — всё. Профиль: аватар, имя, одна полоса статистики, одна карточка. Воздух между блоками 40–64pt.
6. **Меню аккаунта — 8 строк с иконками** (имя+план, лимит с процентом, Show Pet, пригласить друга, настройки ⌘,, разделитель, справка, выйти) в отдельной всплывающей панели #292929 внизу слева. Шорткаты серым справа.
7. **Действия экрана — текстом с иконкой в правом верхнем углу** («Изменить», «Пригласить друга», «Закрытый», «Поделиться»), без кнопок-плашек. Основная кнопка на экране одна.
8. **Поле ввода — это и есть интерфейс.** Внутри: «+» (прикрепить), тумблер «Подтверждать за меня», выбор модели справа, микрофон, круглая белая кнопка голоса. Под полем вторая строка-полоска чуть светлее: «Выбрать проект · Файлы · Плагины». Подсказки ниже — с иконкой сервиса слева, текст серый, одна строка, обрезка «…».
9. **Статистика — одна горизонтальная полоса-таблица:** 5 ячеек, вертикальные разделители, значение сверху (16pt белый), подпись снизу в две строки (13pt серый), по центру. Без иконок, без цветов.
10. **Левая рейка из 7 иконок** (дом, проекты, история, библиотека, @, ещё, плагины) серых #8e8e8e, активная белая; аватар внизу. Сайдбар списка #1c1c1c чуть светлее основы #171717 — граница видна без линии.

## 4. Наш стиль = простота ChatGPT + почерк киношников

Повторять нужно **структуру и тишину**, а не палитру. Уникальное — в трёх вещах:

1. **Янтарная лампа.** Один тёплый акцент вместо белого: главная кнопка экрана янтарная (`--accent`), всё остальное белое/серое. Лампы статуса кадра (красная/янтарная/зелёная, приглушённые) — как на пульте монтажной. Это сразу отличает нас от «ещё одного чата».
2. **Хлопушка и таймкод.** Там, где у ChatGPT статистика «токены за всё время», у нас — «сцен разобрано · кадров принято · минут аниматика · дней до съёмок · текущая серия дней работы». Цифры моно (JetBrains Mono), подписи обычные. Номера сцен/кадров `12.3` и таймкоды `00:04:12` — единственное место для моно.
3. **Лист, а не чат-пузырь.** Сценарий, разбивка, карточка кадра — это «листы» (surface) с полями, как бумага на тёмном столе; помощник NEYRA — поле внизу, как композер ChatGPT, но с кино-действиями внутри: «+» (прикрепить сценарий/кадр), тумблер «Принимать за меня» (автоприёмка черновиков), выбор этапа (Сценарий · Раскадровка · Аниматик · Пост) вместо выбора модели, микрофон. Подсказки под полем — три типовых дела дня: «Разбей сцену 12 на кадры», «Покажи, что не принято», «Собери смету на неделю».

## 5. Что исправить в `dizayn/tokeny.css` и `okno-proekta.html` (конкретно)

```css
:root{
  --bg:#171717; --bg-side:#1c1c1c; --surface:#212121; --surface-2:#2c2c2c; --field:#343434;
  --line:#2e2e2e; --line-strong:#383838;
  --text:#ececec; --muted:#9a9a9a; --dim:#6f6f6f;
  --accent:oklch(0.82 0.11 75); /* янтарь — одно действие на экран */
  --r:16px; --r-field:24px; --r-pill:999px;
  --fs-label:13px; --fs-text:15px; --fs-lead:17px; --fs-title:26px;
}
.btn-main{ background:var(--accent); color:#1a1a1a; border-radius:var(--r-pill); height:40px; padding:0 18px; font-weight:600 }
.btn-ghost{ background:transparent; color:var(--text); border:1px solid var(--line-strong); border-radius:var(--r-pill); height:40px; padding:0 18px }
.field{ background:var(--field); border-radius:var(--r-field); padding:14px 16px; border:1px solid transparent } .field:focus-within{ border-color:var(--line-strong) }
.stats{ display:grid; grid-auto-flow:column; border:1px solid var(--line); border-radius:var(--r) } .stats > div{ padding:18px 12px; text-align:center; border-left:1px solid var(--line) } .stats b{ display:block; font:600 16px/1.2 var(--mono) } .stats span{ font:400 13px/1.3 var(--body); color:var(--muted) }
.menu{ background:#292929; border-radius:var(--r); padding:8px; width:300px } .menu a{ display:flex; gap:12px; align-items:center; height:40px; padding:0 12px; border-radius:10px; font-size:15px } .menu a:hover{ background:#333 } .menu kbd{ margin-left:auto; color:var(--muted); font:13px var(--body) }
```

- Капс-подписи моно → обычные 13px серые (кроме номеров кадров/таймкодов).
- Радиусы 10/6 → 16 листам, 24 полю, пилюля кнопкам.
- Колонка цехов светлее основы, без линии-границы.
- Одна кнопка с заливкой на экран; остальные — контур или текст с иконкой.
- Иконки — Lucide 20px, `stroke-width:1.5`.
- Меню аккаунта внизу левой колонки, 8 строк, шорткаты серым справа, разделитель перед «Справка».
- Экран проекта по умолчанию почти пуст: заголовок-вопрос, поле, три подсказки; листы появляются по действию.
- Бумажный режим оставить (у ChatGPT тоже есть светлая тема), значения по той же логике: основа #f7f7f7, колонка #ffffff, поле #efefef.

Проверка «похоже ли»: закрыть логотипы — экран должен читаться как рабочее приложение, а не как сайт; на 375px колонка уходит, поле прилипает к низу, три подсказки остаются.
