# Блок «Токены» (№60, 13.10.2026)

Решение Александра: все, кто хочет попробовать, сразу получают вход, пакет токенов и возможность докупить.

## Что есть
- **Кошелёк на ключ.** Создаётся при первом касании (`/api/me`, `/api/tokeny`, вопрос помощнику). Всем — пробный пакет `probnyy_paket`; роль `admin` (владелец студии) — без лимита.
- **Пробный вход без ключа.** `POST /api/proba {name, email}` → свой проект `proba-xxxxxxxx`, ключ продюсера на него, пробный пакет. Один вход на e-mail; не больше 30 в час с сервера. Ответ содержит `okno` — ссылку на окно с ключом (`/studio/?klyuch=…`), окно сохраняет ключ на устройстве и убирает его из адреса.
- **Списание.** Вопрос помощнику стоит `ceny.vopros` (по умолчанию 1). На нуле — `402 TOKENY_EMPTY`, окно показывает, где пополнить. Картинки и видео (`kartinka`, `video`) — цены заданы заранее, списание подключится вместе с генерацией.
- **Пополнение.** Участник оставляет заявку (`POST /api/tokeny/zayavka {tokeny, sposob}`); владелец (`admin`) видит заявки (`GET /api/tokeny/zayavki`), начисляет (`POST /api/tokeny/nachislit {keyId, tokeny, zayavkaId}`) или отклоняет (`POST /api/tokeny/zayavki/<id>/otklonit`). Онлайн-оплата — ссылкой `ssylka` в `oplata.json`, когда появится (Stripe/Kaspi Pay).

## Конфигурация (читается при каждом запросе, перезапуск не нужен)
- `~/.config/neyra-studio/tarify.json` — пробный пакет, цены, пакеты (образец `server/tarify.example.json`). Переменная `NEYRA_TARIFY_FILE`.
- `~/.config/neyra-studio/oplata.json` — способы оплаты и реквизиты (образец `server/oplata.example.json`). Переменная `NEYRA_OPLATA_FILE`. Реквизиты и цену токена задаёт только Александр; в коде денег нет.
- На сервере деплой кладёт оба файла из `~/.config/neyra-studio/` мака в `/root/.config/neyra-studio/`, если они есть.

## Данные
`<data>/tokeny.json` — кошельки и заявки, пишется атомарно под общей блокировкой хранилища. История кошелька — последние 200 движений.
