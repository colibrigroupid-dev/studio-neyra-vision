# Чек-лист приёмки · что проверяет партнёр перед «проверено»

Проверяется построенное, не намерение: открыть в браузере, снять экран на 1440 и 375 px, пройти список. Результат — файл `proverki/NN-<кратко>.md`: что проверял, чем, что нашёл (файл и строка), вердикт.

## Форма
- [ ] Первый экран без прокрутки отвечает: что это, для кого, что сделать
- [ ] 375 px: нет горизонтального скролла, ничего не обрезано, кнопки ≥ 44 px, текст ≥ 16 px
- [ ] Один акцентный цвет; контраст текста ≥ 4.5:1
- [ ] Кадры 16:9, резкие, в одном цветовом настроении; у `<img>`/`<video>` заданы размеры
- [ ] Русский и казахский переключаются; казахские буквы отрисованы шрифтом страницы, не подменой
- [ ] Длинные имена и слова (проверить «Нурсултан Жаксылыкович Абдрахманов-Сейтказиев») не ломают вёрстку

## Содержание
- [ ] Каждый блок прочитан как посетителем: что сказано и правда ли это
- [ ] Имена, цифры, цены, сроки, ссылки — настоящие; придуманных нет; где решения нет — на доске «решение Александра»
- [ ] Публично «Neyra Vision» и «технология NEYRA»; названий моделей и Neyra Labs нет
- [ ] Нет служебных пометок, плейсхолдеров, «откуда взято»
- [ ] Анна и Анара — первыми и одинаково; «Ара Аруш» не склоняется

## Поведение и техника
- [ ] Все ссылки и кнопки ведут куда надо; главная кнопка повторяется в конце
- [ ] Консоль без ошибок, в сети нет 404; без JS контент виден
- [ ] `prefers-reduced-motion` уважается; движение не дёргается на телефоне
- [ ] `<html lang>`, `<title>`, description, Open Graph с картинкой 1200×630, favicon, `theme-color`
- [ ] Ключи, токены, пароли — не в репозитории (`.gitignore`, `~/.config/...`)
- [ ] Для рабочего пространства: данные переживают перезагрузку; «готово» и «принято» различимы; без прав нельзя менять чужой раздел

## Сценарий и рабочее пространство (приоритеты Codex, 13.10)
- [ ] Текст автора сохраняется дословно; ИИ предлагает изменения отдельно; импорт не заменяет существующий сценарий незаметно
- [ ] Версии сценария восстанавливаются с сохранением текущего черновика
- [ ] Язык интерфейса не меняет язык и текст сценария
- [ ] Изменение сценария сохраняет материалы кадров и помечает, что их надо пересмотреть
- [ ] Пользовательский ввод (имена, сценарий, комментарии) выводится безопасно, не превращается в HTML
- [ ] Ошибка сохранения не выдаётся за успешное сохранение
- [ ] Демонстрационные функции и локальное сохранение обозначены честно
- [ ] Права в командном модуле проверяет сервер, а не только интерфейс
- Команды: `node --check studio/app.js studio/data.js studio/timeline.js`, `cd studio && node verify.mjs`; для редактора — `node --check scenariy/app.js scenariy/fountain.js`

## Вердикт
`принять` — всё выше выполнено или отклонения оговорены на доске. `доработать` — список дефектов с файлом и строкой, без правок в чужой зоне.
