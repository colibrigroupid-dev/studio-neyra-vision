## 13.10.2026 · Codex (задача №15, сервер хранения)
- По прямому поручению Александра создан `server/`: `app.py` на Python 3.9+ со стандартной библиотекой, ThreadingHTTPServer, порт по умолчанию 8770. API: проекты, черновик и версии сценария, сцены, кадры со статусами draft/working/review/approved, участники с ролями и ссылками keyId на внешний конфиг. Маршруты, схемы, права и curl описаны по-русски в `server/API.md`; `server/keys.example.json` содержит только пустые секреты.
- Проект хранится в `server/data/<slug>/project.json` (исключён через `server/.gitignore`): временный файл в той же папке, flush/fsync, os.replace; блокировка охватывает чтение, проверку и запись. Восстановление сохраняет текущий черновик и сцены как backup, создаёт restored и меняет черновик одной записью. Материалы кадров сохраняются и отмечаются needsReview. Ошибки записи возвращают 500 STORAGE_WRITE_FAILED; отказ диска не меняет прежние данные. ETag/If-Match предотвращает запись устаревшей редакции по запросу клиента.
- Ключи читаются только из внешнего `~/.config/neyra-studio/keys.json` (путь можно задать аргументом). Авторизация проверяет роль, проект, разделы и членство; секреты не возвращаются, не пишутся в проекты и не логируются. Изменение или отзыв конфигурации действует со следующего запроса. JSON экранирует <, >, & на проводе, сохраняя авторский текст дословно после декодирования. Статика ограничена публичными страницами/ресурсами; server/, скрытые файлы, Python/Markdown/JSON, обходы путей и закрытые цели символьных ссылок не выдаются.
- Проверено: 25 unittest прошли командой `NEYRA_TEST_TRANSPORT=inprocess PYTHONDONTWRITEBYTECODE=1 python3 -m unittest server.test_api -v` (0,207 с); синтаксис Python, пустой шаблон ключей, git diff --check и исключение server/data/ также проверены. Тесты покрывают реальный HTTP Handler, права, восстановление, перезапуск, параллельные изменения, отказы rename/fsync, HEAD, статическую раздачу и границы пользовательского ввода. Находки внутренней проверки Codex исправлены с воспроизводящими тестами; это не партнёрский статус «проверено».
- Ограничения среды: обычный сетевой запуск тестов не смог открыть локальный порт (PermissionError при bind). Режим inprocess явно передаёт HTTP-байты тому же Handler и не подтверждает TCP-запуск.
